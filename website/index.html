SOURCE INSTALLATION

Try the runtime from main.

Requires Node 24.9+, npm, and Git.

Install from main with the matching DSH 0.2.1-rc.3 compatibility runtime: 19 native packages across 43 file paths.

The launcher prepares a separate Web environment with its own home, configuration, and documents directory. It does not install into your personal Desktop app.

First-run & rollback guide↗
TERMINAL 
git clone --branch main --single-branch https://github.com/Burns1028/moa-plus.git
cd moa-plus
npm ci
node scripts/apply-native-compat.mjs --dry-run
node scripts/apply-native-compat.mjs --backup "$PWD/.superpowers/native-backup"
npm run build
node scripts/project-mode.mjs setup --dir /absolute/empty-moa-runtime
node scripts/project-mode.mjs start --dir /absolute/empty-moa-runtime
Configure your model in native settings. Select MoA+ before the first message of a new conversation.
